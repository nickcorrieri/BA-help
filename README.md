# BA Help — Tools Repo

A collection of business-analyst tools built for restricted / PII-approved environments. No blind package installs; everything runs on what's already there (Excel, Python stdlib, or Node.js).

## Projects

| Folder | What it does |
|--------|-------------|
| [`nurse-course-gap-finder/`](nurse-course-gap-finder/) | For transferring nurses: compares required courses for a new job code against courses already taken, flags gaps and near-matches for human review. |

---

Each project folder has its own README with setup and run instructions.
